# 共同死因掃描 —— 已結案判決的橫向讀法

**2026-09-11。這份檔案裡沒有判決，只有假說。**

起因是使用者的一句話：讀完外部文章之後，`docs/external_reading.md` 裡最有價值的
連結（「三個症狀是同一個缺陷」）**所需的資料全部在這個 repo 裡**，而我們自己
沒有做出來。使用者指出：「但是我自己想不到你也沒想到。」

那不是資訊不足，是**模式不對**。這個專案有一台很好的**否證**機器
（預註冊、CI 判準、守衛要紅一次、SE 要用判決那台機器算），
而它沒有任何一個**產生候選框架**的機制。每個判決被關掉之後就歸檔，
而歸檔正是橫向洞見的敵人——它把項目移出視野。

所以這一支的工作只有一件：**把已結案的判決橫著讀一次，找共同死因。**

---

## 使用規矩（比內容重要）

1. **這裡的每一條都是假說，不是判決。** 事後找到的模式通過多少一致性檢查
   都不算數（mistake.md 2026-09-09）。要變成判決必須走
   `.claude/rules/factor-research.md` 那十道，而且**挑選程序本身要進樣本外**。
2. **每條假說必須列出成員清單與反例**，否則它只是一個好聽的敘述。
3. **不得用這份檔案去復活任何已結案的線。** 共同死因的用途是
   **改變我們開下一條線的順序**，不是重審舊判決。

## 假說 1 —— 資訊層過、執行層死，而且我們每次都在最後才發現

**這是最大的一群，而且它在多個判決裡被我們自己寫出來過，只是沒有被命名。**

| 節 | 資訊層 | 執行/經濟層 |
|---|---|---|
| **4.65** 分鐘級系統 | G1 資訊存在 **PASS**（15/15 月同號、IC 峰在 15-30m） | G2 經濟可行 **FAIL**（138 格淨值全負，最好一格毛利 6.2bps < 8bps 門檻）|
| **1.03i** 清算位密度 | H1–H4 **全過**（真值 CI 下緣 +0.1316、位置安慰劑 p=0.0196、多空同號、半衰期單調） | 交易假設**沒過** |
| **1.02** 掃單失敗舊線 | 引擎自審六項全過，**訊號有效性未被推翻** | 歷史 edge 是**成交假設**造出來的（57.9% 的交易記「成交在價位」，市場距價位中位 42.6 bps）|
| **1.03b** SDV 進場定義 | 毛利為正且 CI 離零 | 誠實錨點後**扣成本全部為負**（delay 1/2/3/5/10 逐幣 2-3/9）|
| **1.03e** 引擎自審 | **引擎是乾淨的** | 抓不到的是方向 |
| **§0.57b** 執行落差 | 天花板顯著為正（+0.0381、9/9 幣、t=3.03）| **落差 +0.0505 > 天花板 +0.0381（132%）**→ 反應式執行淨值必為負 |
| **1.18b** 路徑 B | — | 被動基準六個場館對**全負** |

**共同形狀**：訊號存在、可被統計檢定、通過安慰劑與置換——**然後在把它換成
可成交價格的那一步死掉**。

**這不是「交易很難」這種廢話。** 尖銳的版本是：

> **我們的流程永遠把「資訊層驗證」排在前面，把「執行可行性」排在最後，
> 所以每一條線都花幾個月才撞到它的約束條件——而那個約束條件每次都是同一個。**

**而我們已經發現過這個修法一次，然後沒有把它變成規則。**
§1.03 的小額實盤測試，當時的理由白紙黑字寫著：
「舊線正是死在這一題上……**這次提前把它做掉，是把舊線的教訓執行出來**」。
我們對**一條線**做了這件事，沒有把它變成**所有線的第 0 關**。

**可做的改法（不需要新資料）**：
在任何新線的預註冊裡，**Gate 0 = 執行可行性**，排在資訊層之前：

```
Gate 0（新增，排最前）
  a. 如果這個訊號完全正確，我在什麼價格成交？
  b. 那個價格在目標場館拿得到嗎？（要有量測，不是論證）
  c. 可實現的邊際 vs 該場館的來回成本，比值是多少？
  d. 比值 < 1 -> 停，不要做資訊層的工作
```

**鏈上線現在就可以套**：§1.10 的機制關目前只問「有沒有機制」。
Gate 0 要先問：**如果燃料圖是對的，我用什麼方式進場、那個價格在 HL 上拿得到嗎。**
而我們**已經有一半的答案**——`resting_limit` 說掛在價位是 −0.0612、
`nofill_distance` 說價格不會回來。那兩個數字應該在機制關**之前**被引用，不是之後。

**反例（必須列出，否則這條假說沒有分辨力）**：
`1.18i` λ 的條件分解——13 個狀態格全部為正，結論是「λ 是狀態的單調函數，
撤單流終於有了位置」。那一節**沒有死在執行層**，它是正面結果。
所以這條假說不是「所有東西都死在執行層」，而是
**「凡是最後死掉的，多半死在那裡」**。

## 假說 2 —— 設計的功效不足：MDE 比效應大

| 節 | 症狀 |
|---|---|
| **0.86** 地形扳機 | 門檻 8pp、SE **11.6pp** ——「那個判準從來就沒有能力做出判決」 |
| **1.18c** 擁擠度橫截面 | NO-GO，但**功效低到只能排除大效應** |
| **1.16** 道哥沙盤交集 | NO-GO（**功效不足**），但符號對 |
| **SDV 本體** | 每筆 SE 0.1904 ⇒ split-test MDE **0.746 ATR**，而最大量到的因子效應 0.287 |

**共同形狀**：不是「測過而且輸了」，是**測不動**。

我們已經有規則（mistake.md 2026-09-04：`SE ≥ 門檻 ⇒ 這個設計不能做決定`），
而且掃過所有開著的時鐘確認只有地形扳機犯這個病。**但那條規則作用在
「凍結判準的當下」——這幾節顯示它應該更早一步：在決定「要不要研究這個題目」
的時候就先算一次 MDE。** 題目選錯比判準寫錯貴。

**可做**：把 MDE 估算加進 Gate 0（與執行可行性並列）。

## 假說 3 —— 我們反覆假設「越極端越強」，而資料反覆說不是

| 來源 | 我們的先驗 | 資料說 |
|---|---|---|
| V7 \|pred\| 五分位（2026-08-24） | 預測越強越準 | **Q1（最強）54.5% / Q5（最弱）64.0%——反的** |
| **1.05** 群眾止損地圖 | 止損聚集處＝爆倉聚集處 | **G3 FAIL：兩者反向排列**，九幣無例外 |
| **0.88h** B2＋只吃串內第一根 | — | **預測反了** |
| **1.14c** 流訊號鏡像消費者 | — | 五道全不過，**方向與預測相反** |
| **1.06** 擁擠度→幅度 | 擁擠→位移 | R1/R4 都沒過，**形狀指向震盪不是位移** |

> ### ⚠ 2026-09-11 更新：**V7 那個成員已被預註冊測試駁回**
>
> §1.11 跑完（`research/prereg_v7_construction.py`，判準凍結於 `59ce0e0`）：
>
>     A 臂（|z| 最強 5%）命中率 **56.48%**（n=386）
>     C 臂（|z| 最弱 20%）命中率 **49.83%**（n=582）
>     差 **−6.65 pp**，CI95 [−13.50, +0.07]，P(C>A) = **2.7%**
>
> **方向跟這條假說相反**——極端值那臂比較好，而且差一點就顯著。
> 依凍結判準 H1 不過，所以正式結論停在「沒有單調關係」，
> **不得升級成「反向」**（判準是單尾的，只准說 C>A 或不說）。
>
> **這不推翻 2026-08-24 的量測，兩者測的是不同母體**：
> 那次是「**Strong 集合之內**」的五分位（全部都是極端值），
> 結論是「在極端之內再更極端沒有比較好」——**那仍然成立**，
> 它的用途是「不要再收緊門檻」。
> 而 §1.11 測的是「**極端 vs 中間**」，答案是極端比較好。
> 兩句話可以同時為真。
>
> **所以這條假說的 V7 成員撤回。** 其餘三個成員（§1.05 止損與爆倉反向排列、
> §0.88h、§1.14c）未被測試，維持假說狀態。
> 這正是這份檔案該有的下場：**它產生候選框架，預註冊測試砍掉不成立的那些。**

**這一條跟外部閱讀那份筆記的 §6(e) 是同一件事**：
V7 的構造是 Quantile 法（只取 rolling top 5%），而該方法的內建假設就是
**「edge 全在極端值」**——被 V7 自己的資料否定。

**所以這不只是「某幾次猜錯方向」，是一個反覆出現的先驗，而它有一個
具體的構造層後果。** 三臂預註冊已經寫在 `research/prereg_v7_construction.py`。
