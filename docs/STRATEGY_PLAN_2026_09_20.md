## 0. 為什麼要重排 `alpha_menu.md`

那份菜單（2026-09-13）的排序軸是 **「資料成本 ÷ 已知答案強度」**，
所以 C 族（MRP／配對）排第一，理由是「只要 K 線，而我們完全沒取樣」。

**今天的結論把那條軸廢掉了。** 我們不缺資料、不缺回測素材——
我們缺的是**前瞻樣本**，而「資料成本低」正好等於「產更多回測素材」。

而且那份菜單有一個內部矛盾：C 族標「完全沒碰」，但 **§1.38／§1.39 在同一天
就把 MRP 判成 NO-GO**（多場館單標的：前半挑權重、後半算績效，樣本外只贏
142/352 = 40%）。

**新的排序軸（三條，全部來自今天）**：

1. **它多快能產生前瞻樣本？**（不是回測素材）
2. **Gate 0 的答案已知，或能在一天內量出來嗎？**（核心原則 11）
3. **執行層已經存在嗎？**（不必寫新的下單層——那是本專案明文禁止的）

## 1. 這個專案每一條線的死因是同一個

| 線 | 死在哪 |
|---|---|
| §1.02 獵取舊線 | edge 是**成交假設**造的；實跑 Gate F 變體 B meanR −0.0130 |
| §1.27／§1.28 MFT | 毛利 **+0.58** vs 費用 **3.00** bps |
| §1.03b SDV | 毛利為正、CI 離零，扣成本後全負（後被 §1.03r 部分推翻） |
| §0.57b 獵取執行 | 落差 +0.0505 = 天花板的 **132%** |
| §4.65 分鐘級 | G1 資訊 PASS、G2 經濟 FAIL（138 格全負） |
| §0.75 套利家族 | 只扣費就不再為正 |

**六條線，同一個死法：edge ≈ cost 或 edge < cost。**
核心原則 11 已經把這件事寫成規則了，但規則只教我們**更早發現死亡**，
沒有教我們**怎麼不死**。

而檔案庫裡有一句話，把這個問題直接講成了解法
（`2025-06-20_ultimate-crypto-arbitrage-guide`）：

> 「也許套利的 edge 大致等於交易成本，但加上獎勵計畫之後你會發現
> **每一塊錢的成交量其實賺 1 bp**。**獎勵計畫讓任何你想得出來的 edge
> 都更容易變現，因為門檻低得多。**」

## 2. 三條候選，按「攻擊死因的直接程度」排

### 路徑 C —— 資金費價差（作者的策略 1，他叫它「無風險利率」）

**我們已經在跑，而且它是全專案唯一一條前瞻樣本正在累積且為正的線。**

`research/results/basis_verdict.json`（2026-09-20 實讀）：

| | 前瞻 n=54（17.8/28 天） | 事前 n=270 | 門檻 |
|---|---|---|---|
| BTC 年化中位 | **7.23%** | 4.05% | ≥ 8.0% |
| ETH 年化中位 | **8.27%** | 3.67% | ≥ 8.0% |
| 負值比例 | **0.037** | 0.215 | ≤ 0.25 |

**現況：ETH 過、BTC 差 0.77pp 沒過**（判準要求兩個都過）。
負值比例 0.037 遠優於門檻，而且前瞻明顯優於事前——carry 環境變好了。

檔案庫對它的說法（`Easy_Alpha_Portfolio` 策略 1）：

> 「這是最容易部署成 MVP 的策略之一……**我一直把它當成無風險利率。**
> 資金費套利看起來是**週期性**的，幾個月前 BTC 上的收益率有
> **130% 無槓桿、持續了紮實的 2-3 週**……好的時候你會想要**很快把它開起來**。
> 值得為此設一個監控收益率的通知。」

**離可下單差什麼**：判決 2026-09-30（10 天後）。零新工程。
**要注意的**：作者說它是週期性的，所以「現在 7-8%」不是這條線的上限也不是下限。
真正的價值可能不是常態跑它，而是**有一個會在 130% 出現時叫醒你的監控**。

### 路徑 A —— 獎勵／補貼（攻擊成本那一側，也就是六條線的共同死因）

檔案庫兩篇都把它排在最前面（`Easy_Alpha_Portfolio` 策略 5、
`2025-09-22_finding-arbitrage-opportunities` 第 7 節）：

> 可能本來就有利可圖）」

> 「留意這種機會是明智的，因為它們**遠遠是最賺錢的**。」

**我們的位置比讀這篇的多數人好**：
- Lighter 帳戶已開（**Premium**，maker 0.40 bps / taker 2.80）
- **掛單–吃單對沖引擎（HMM）已經寫好而且在 Lighter 上跑過真單**
- HMM 逐筆分解（2026-09-15 修正儀器後）：賺到的半價差 +7.67、
  逆選擇 −4.01、**淨 +3.67 bps/筆**

也就是說：**我們已經有一個淨值為正的做市腿在 Lighter 上**。
獎勵是加在那個數字**上面**的，不是取代它。

**但這一條要先回答的是一個事實問題，不是研究問題**：

> **Lighter 現在的積分／獎勵計畫，實際付多少？怎麼計分？**
> maker 量算不算？有沒有排除條款（洗量）？我們的 Premium 等級影響什麼？

這是**查證**，不是回測。查完才知道要不要做。**在查到數字之前，
本檔不對這條路徑給任何期望值。**

**邊界**：HMM／Lighter 整條線 2026-09-15 已搬到 `../arb`，
所以這條路徑的執行要從 arb session 開。本檔只負責指出它存在。

**風險（必須寫下來，因為它跟我們過去的風險不同類）**：
- **計畫風險**：補貼停了就只剩下那個本來會虧的策略。作者原話就是這個意思。
- **洗量條款**：作者提到 Lyra「確實撤銷了幾個錢包的獎勵」。
  刷量是明確禁止的，而我們的 HMM 是真的在做市，這是優勢不是風險。
- 這**不是 alpha，是補貼收割**。風險來源是計畫條款不是市場。
