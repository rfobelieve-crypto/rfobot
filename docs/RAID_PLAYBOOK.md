## 二、配方清單（十月預註冊待驗，全部有具名出處）

**反轉確認**（亮了才 fade）：
- `R∧V` 收回∧量能——組合搜尋 t+6.7，變體 D 正在 forward 對照
- **彈簧劇本**：深穿越∧收回（∧量能更肥 +0.245/反轉72%）——R∧V 的肥肉
  在中深穿越，不在 B 的淺區（深淺×流表）
- **三段式序列** `R+∧P+`：獵取(OI↓∧順破)→事後(CVD翻∧OI回升)——突破率
  43% vs 基準 62%，兩半穩定（操作者假設，已證實）
- `pred_align`：V7 模型站在 fade 這邊——netR IC 逐折 4/5 正、CI 全正

**否決**（亮了就不接）：
- 慢回踩∧流仍追（−0.256/WR28%，四切面）
- **假沖洗** `R+∧P−`：獵取像止損沖洗但事後未確認（−0.199，四格最毒）
- gap 期 OI 崩（−0.51/−0.22 兩半）
- 真空推進：吸收低∧量能極端（突破 23-28%，四切面）

**延續識別**（等突破而非 fade 的場景）：
- 收在外側（¬R，突破 22%）·攻擊拖長·獵取後 CVD 續順破（**雙源**：
  flow_bars + Coinglass 皆 70%）·清算第二波

**已處決（勿再測）**：追價佔比、吸收（獨立資訊零）、期貨CVD當小時（兩半
不穩）、事前佈局、OI 環境分位、htf 對齊、276 個 V7 特徵移植（fold NO-GO）。

## 三、評分模型（「訓練系統」的原型，已過 gauntlet）

**存活者堆疊**：7 特徵（pierce/攻擊分鐘/收回/量能/Q/清算爆量/pred_align）
→ XGB → 反轉機率。5 折擴窗 OOS：**top-20% 訊號 WR 63%、netR +0.110**
vs 基準 55%/+0.043，bootstrap CI 全正。
- 對照組：全池 276 特徵版 fold gauntlet NO-GO——**只有掙得席位的特徵
  堆得出東西**
- 冷啟動：訓練 <~300 筆時模型有害（第一折 AUC 0.46）
- 期望管理（三次重現的結構）：**「會不會反轉」高度可測（AUC ~0.84），
  「反轉賺多少」只弱可測（IC ~0.1）**→ 評分用來挑單，不用來調倉位

## 六、判讀鐵律（本檔案的靈魂）

- cohort 定義凍結，被打臉是功能不是故障
- 具名假設先寫預測再看數據；全格報告不挑格
- 單變量過 ≠ 有增量；aggregate 過 ≠ per-fold 過
- 方向可測、肥瘦不穩——不要用肥瘦數字做規模決策
- 符合預期的結果最危險（它讓你停止檢查）

## 七、與 V7 的交會：池子定義是共用的（2026-08-02）

同一套池子（swing / session / pdh_pdl / pwh_pwl，見 GLOSSARY §八）在兩條
線扮演不同角色：

- **本策略**：直接交易池子——被戳破 → 收回 → 賭反轉（變體 A-E）
- **V7 地形層**：不交易池子，用「離池子多遠」當 V7 訊號的品質背景
  （定案四維 D1/D2/D3/D5，display-only，凍結扳機在跑）

10 維地形戰役對本策略的**外溢結論**（都不改本策略任何規則，只影響未來
配方設計時的先驗）：

- **掃過的池子＝死的**：D6（翻轉位）與 L1-A（清算爆量現場）兩次獨立
  驗證，被消耗掉的流動性當支撐**完全無效**。任何想用「歷史被掃價位」
  當配方成分的點子，先看這兩個結果
- **清算資料只有金額、沒有熱圖**：Coinglass 逐時清算額能做的只有「爆量
  現場」（已證無效當支撐）與「爆量倍數」（drv_liqburst，已在 shadow
  前瞻記錄中，屬十月預註冊範圍）
- **池子等級（週>日>波段>時段）不顯著**：D4 方向對但 +3.6pp 不到門檻
  ——配方裡不要預設「週線級池子比較肥」，目前沒有證據
- **市場結構語言（BOS/CHoCH/結構方向）對 V7 訊號零席位**：注意這**不
  等於**它對本策略無效——本策略的 ¬R（守住）本來就是 BOS、R 就是假
  BOS，那是事件本身；地形測的是「事件之後 V7 訊號的品質」，兩件事
