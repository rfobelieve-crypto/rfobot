## 一句話

**POC 距離沒有獨立的判別力，而且它在 sellside 的方向跟假設相反。**
兩側的訊號都被它的混淆對照（VWAP 距離＝同窗成交量加權**均價**的距離）吸走

## 分位單調性（全格報告，L2，τ=1h）

**sellside — 單調，而且是假設的反方向：**

| 桶 | n | 均值 | 中位 | 延續率 |

延續率隨 POC 距離**單調下降** 48.9% → 38.0%。H1 說「POC 遠 → 延續」，
資料說「POC 遠 → **反轉**」。

**buyside — 弱單調，方向與假設一致：**

| 桶 | n | 均值 | 中位 | 延續率 |

**兩側方向相反**——這是「兩側分開判、不池化」這條註冊設計唯一有用的一次：
池化會讓兩邊互相抵銷成「什麼都沒有」。

## 儀器與資料限制（規格要求揭露的，以及跑出來才知道的）

**1. 5m 重建誤差（報告 01，量出來不是說出來）**
同一批事件比 1m 真值：**5m 均勻攤量中位位移 0.050 ATR = 剛好一格**
（BTC 580 / ETH 584 筆，q90 0.30/0.40，46%/38% 落同一格）。修訂 C 的守衛
= 3×0.050 = **0.15 ATR**；實際 q75−q25 = **1.88 / 1.81 ATR = 守衛的 12 倍**
→ 判別變數有變異，**不判 INCONCLUSIVE**。不需要升級 1m 全幣。
替代分配法（全給 close 格）中位誤差 0.30/0.35、q90 **2.75/2.90 ATR**，
是主方法的 6–7 倍——**兩種分配法不對等**（修訂 D，寫在看結果之前）。

**2. `POC_dist > 0` 是恆等式，不是發現**
L1/L2 兩側 **100.00%** 為正（L3 才 98.4%）。被掃價位依定義是近期極值、
POC 在區間內部。所以「部位群在獵取區的反方向」這句話攜帶**零資訊**；
有資訊的只有距離的遠近。原 §6.1 的「>85% 落在同一側就停」因此是恆真句
（修訂 C 已改寫成寫在幅度上的守衛）。

**3. 重複事件率 25.7% / 23.4%，最大一組 27 筆**
同一根 1h bar 上多個相近價位的樞紐各自成事件（2025-10-10 的 ADA 在一個桶裡
出現 4 次同值）。有效樣本是 **~4,910 / 4,919 個（幣, bar）組**，不是 6,608 /
6,420 列。§10 註冊的「±3 tick + 冷卻 60/300/900 秒」只合併 **492–493 筆
（3.8%）**——秒級冷卻在 1h 事件粒度上幾乎不作用，這是註冊時就該預見的。
日聚類 bootstrap 有吸收掉大部分（同 bar 必同日），CI 之所以那麼寬就是它。

**4. 判準 (c) 幾乎不出力**
τ 的標籤是**嵌套的**（r_15m ⊂ r_30m ⊂ …），符號天生高度相關。
**打亂標籤的對照跑**（`11_verdict_perm.json`）在純雜訊下就出現兩次 5/5 同號。
(c) 已註冊故照用，但它不構成證據。

**5. 註冊時的 SE 低估了 9 倍——這條要進 mistake.md**
註冊時算 SE 用逐 bar 報酬的 σ=0.702、且沒有把聚類算進去，得 SE(Δ)=0.025。
實際：事件條件下 σ(r_1h)=**1.20**（尾巴更肥），加上日聚類與上面的重複事件，
bootstrap 實測 **SE(Δ) ≈ 0.23 ATR**。也就是這個設計真正能分辨的效應量級是
**~0.45 ATR 起跳**，不是 0.089。它**還是做出了判決**（CI 有排除零，也有
含零），但「經濟錨 0.089」那一關在這個解析度下沒有實質作用。
**打亂標籤的對照沒有救到這件事**——置換恰好破壞掉「同日標籤相關」這個
使變異數膨脹的結構，所以置換版的 CI 天生偏窄。

**6. §9 幣別異質性（n=9，只看方向）**
Spearman(逐幣 POC_conc 均值, 逐幣前瞻 net_R 均值) = **+0.367，p=0.332**。
方向與「集中度高→反轉多」一致但**不顯著**，n=9 沒有統計力。
**不能用來解釋 Gate F 前瞻 5/9 幣為正的不一致**，那個不一致要另找原因。

## 未註冊的殘留觀察——**不得據此行動**

sellside 上真正扛著效應的是 **VWAP 距離**（離近期成交量加權**均價**多遠），
t = −2.75 / −3.57，而且是在 `trend_24h`、`er_24h`、`rv_1h`、`rv_24h`、
`pierce_atr`、時段全部控制之後的**增量**。方向是「離均價越遠 → 越容易反轉」。

這**不是**本節的假設，沒有被預註冊，**不得當成發現**。它跟已經測過的
地形族／趨勢族可能只是同一件事的另一個名字（「價格拉伸得多遠」）。
要用它必須走它自己的預註冊、在不重疊的資料上，並且先回答一個問題：
它跟 §0.49 的生存條件層（ADX regime）與 §0.94 的地形族是不是同一個軸。
