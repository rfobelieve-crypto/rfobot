# 撤單流用於「出場側」— 預先登記

登記日：2026-07-28（門檻在看到**任何**本測試結果之前寫定，以本檔 git
commit 時間戳為證）
提案人：使用者（2026-07-28，「撤單流我也覺得是突破的一個點」）
整理：Claude

---

## 為什麼要獨立登記一份

撤單流已經被評估過三次，三次的結論都不支持現有用法：

| 用法 | 結論 |
|---|---|
| 當 V7 的 4h 特徵 | **NO-GO** — horizon 錯配，100ms 訊號壓成 1h 殺掉資訊 |
| 當獨立分鐘級系統 | Phase 0 **G1 PASS / G2 FAIL** — 資訊在，但清不過成本地板 |
| 當進場 overlay | 被判為「自然歸宿」，但**從未測過**（PARKED） |

**出場側是第四種用法，從來沒有人提過**，而它的結構跟前三種不同：

1. **成本地板不適用。** 殺死 Phase 0 的是「4bps maker 來回成本 > 30m 毛利」。
   出場時本來就要出，只是時機不同，**沒有增量交易成本**。
2. **不需要方向預測。** 進場問「會漲會跌」；持倉只問「這個回撤是真的還是
   假的」——後者是嚴格較弱的問題。
3. **它正對著 `trail_stop` 的痛點。** 現行停損是固定 3xATR 距離，完全分不出
   洗盤與反轉；回測 WR 37.0%、live n=10 平均 −0.68%。

## 為什麼現在測、而且不等交易樣本

`depth_deltas_1m` 目前 19 天（163k 分鐘）。落在這個窗內的 live 交易只有
**2 筆**（id 19、20），45 個出場決策點——直接測出場**測不動**。要湊到
30-50 筆交易需要再等 3-5 個月。

所以本測試**刻意把假說與交易樣本脫鉤**：出場真正要回答的問題（回撤是洗盤
還是反轉）不需要持有部位才能問。19 天裡有數千個回撤事件，每一個都是樣本。
先在充足資料上驗這個底層問題，過了再談接到 executor。

## 假說

在價格自局部極值回撤達 trail_stop 距離的那一刻，**撤單流狀態能區分
「回撤將延續」與「價格將收復極值」**。

方向性預期（來自 v3 `classify_minute_lead` 已凍結的映射，非本次新造）：
賣方掛單被抽走（`ac_shock` 高）→ 上方阻力消失 → 偏向收復；
買方掛單被抽走（`bc_shock` 高）→ 下方支撐消失 → 偏向續跌。

## 事件與標籤定義（跑之前寫定，不得事後調整）

**事件**：對每一分鐘 t，以 `TRAIL_MULT × ATR = 3.0 × ATR`（對齊現行
executor，非掃參）為門檻。維護過去 240 分鐘內的滾動極值：
- 多頭情境：價格自 240m 最高點回撤 ≥ 3×ATR
- 空頭情境：價格自 240m 最低點反彈 ≥ 3×ATR

ATR 取 1h Wilder-14 換算至該分鐘（與 executor 同源）。每個極值只計一次
事件（首次觸及回撤門檻的那一分鐘），避免同一段回撤重複計數。

**標籤**（三個前瞻窗**全部報告，不得只挑最好的**）：
M ∈ {30, 60, 120} 分鐘後，
- `RECOVER` = 價格回到觸發前的極值（多頭情境）／回落至極值（空頭情境）
- `CONTINUE` = 未收復

**特徵**（僅用現有凍結定義，不新造、不調參）：
- `ac_shock`, `bc_shock` = 該側 cancel 量 / 該側 trailing-60m 中位數
  （`cancel_playbook_watcher.py:241`，FROZEN v1 2026-07-16）
- `skew15`, `net15` = FROZEN v1 定義（同檔頂部註解）
- `vshock` = volume_usd / trailing-60m-median(volume_usd)

## 通過門檻（GO 需**全部**滿足）

1. **效果量**：conditional `RECOVER` 率相對該情境 base rate 差距 **≥ 5 pp**
2. **統計**：bootstrap 95% CI **不含 0**（2000 次重抽）
3. **穩健性**：**30/60/120 三個窗方向同號**（防挑窗）
4. **樣本**：每個分組 **≥ 200** 事件；低於此報「樣本不足」，**不報結論**

任一項不滿足 = **NO-GO**。邊際結果不得以「趨勢正確」解釋為部分通過。

## 本測試通過**不代表**什麼

- 不代表可以接進 executor。通過只換得「值得用真實出場決策點驗證」的資格，
  那仍需 3-5 個月累積 30-50 筆乾淨交易。
- 不代表撤單流有進場 edge。本測試完全不涉及進場，8/10 那份 PREREG 獨立有效。
- 本測試在**單一 19 天窗**上進行，非獨立樣本外。

## 已知偏誤與處理

- **重疊事件**：回撤事件在時間上可能重疊，bootstrap 以事件為單位重抽，
  不宣稱獨立同分布；效果量門檻設在 5pp（高於一般顯著性）部分補償此點。
- **單一 regime**：19 天只涵蓋一種市場狀態，這是已知限制，不以樣本數
  （數千個分鐘事件）掩蓋——**有效樣本接近事件數，不接近分鐘數**。
