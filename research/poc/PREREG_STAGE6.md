## 2. 主檢定：迴歸，不是分位差

原規格的主檢定是「趨勢分桶內 q75 vs q25 的**均值**差」。用 `power.py`
在真實標籤上以日聚類 bootstrap 量它的離散度（B=2000，只取離散度）：

| side | 估計量 | SE | MDE（CI 排除零） |
|---|---|---|---|
| sellside | **均值臂（原規格）** | **0.5065** | **0.9928** |
| | 中位臂（事件層） | 0.3387 | 0.6638 |
| | 日聚合 | 0.0858 | 0.1682 |
| | **迴歸 β1 × IQR** | 0.1216 | **0.2383** |
| buyside | 均值臂（原規格） | 0.1110 | 0.2176 |
| | 中位臂（事件層） | 0.0559 | 0.1096 |
| | 日聚合 | 0.0919 | 0.1801 |
| | **迴歸 β1 × IQR** | 0.0854 | **0.1674** |

**原規格的主檢定在 sellside 需要 0.99 ATR 才判得動**——11 倍於凍結規則
每筆的全部 edge。**那是註冊即無效**（mistake.md 2026-09-04 同族）。

原因量出來了：**2025-10-10 一天供給 2.5% 的 sellside 事件、97% 的估計量
變異數**（該日 157 筆、均值 −4.99、std 8.15）。剔除那一天，sellside 的
SE 從 0.5048 掉到 0.0800，buyside 幾乎不動。均值臂在肥尾下等於擲硬幣看
那天有沒有被重抽到。

**逐側挑最好的估計量是選擇偏誤，所以只選一個。** 選迴歸，理由三條，
**都與任何點估計無關**：
1. 兩側功效**平衡**（0.238 / 0.167），其餘三個都嚴重偏一側；
2. 用到**全部**資料，不是只用兩個分位臂；
3. **它內建那個混淆對照**（`vwap_dist`）與逐幣固定效果——而 H1 的成立與否
   本來就取決於「扣掉均價距離之後還剩不剩」。

### 主檢定的形式（凍結）

```
r_norm_1h ~ poc_dist_L2 + vwap_dist_L2 + trend_24h + er_24h
            + rv_1h + rv_24h + pierce_atr + 時段固定效果 + 逐幣固定效果
標準誤：以 UTC 日聚類（跨幣共用同一天，因為 2025-10-10 同時打到九幣）
兩側各跑一次，不池化。主格 = L2 × τ=1h。
```

## 3. 判準（凍結；每一條都寫在 CI／t 上，不寫在點估計上）

```
PASS          β1（含 vwap_dist）的日聚類 |t| > 2.5
              且 **符號與 H1 預測一致（β1 > 0）**
              且 跨 τ 同號 ≥ 4/5（報告用，不單獨構成 PASS）
REJECT        |t| < 1.5
              或 |t| > 2.5 但**符號相反**
INCONCLUSIVE  1.5 ≤ |t| ≤ 2.5
```

**三分法是刻意的。** 舊規格只有 PASS / REJECT，中間帶沒有定義，於是一個
「測不出來」會被記成「測過而且輸了」——地形扳機就是這樣被誤記的
（mistake.md 2026-09-04）。

**符號相反且顯著 ≠ 發現。** 那是 H1 被推翻，反向效應要走**它自己的**
預註冊、在不重疊的資料上。舊管線在替代分配法下出現過 t = −3.06，
1m 仲裁顯示它附著在一個跟真值只有 0.33 相關的估計量上。

### 經濟錨與這個設計的解析度下限（誠實揭露）

凍結規則每筆的全部 edge = +0.0255 R × 3.5 = **0.089 ATR**（換算到本管線
略小 6% 的 ATR 單位約 0.094）。而主檢定的 MDE 是 **0.238 / 0.167**。

**也就是說這個設計分辨不了「剛好等於整條策略 edge」量級的效應。**
它能判的是 **~0.2 ATR 以上**的效應；低於那個量級它會回 INCONCLUSIVE，
**不會回「沒有效應」**。這句話寫在這裡，是為了讓 INCONCLUSIVE 不被事後
讀成 REJECT。

## 4. 穩健性（報告，不構成判定）

- 三個 lookback（L1 含 60 根下限 / L2 / L3）× 五個 τ 的 β1 與 t
- 分位差三個版本：均值臂（原規格，續用以便與舊結果對照）、中位臂、日聚合
- 五分位單調性，**全格報告不挑格**
- 逐幣 β1（九幣，尾巴厚度差 20 倍，必須逐幣看）
- 替代攤法（close-bin）——**依修訂 D，它不得單獨推翻或支持主判定**，
  仲裁者是逐筆真值
- 冷卻期 60 / 300 / 900 秒（已知在這個資料上沒有分辨力，照報）

## 5. 必須一起報的三件事（Stage 5 註冊，因為六天承載整條尾巴）

1. CI 一律**日聚類**（跨幣共用同一天）
2. 點估計**同時報均值、中位、日聚合**三個版本
3. **逐幣報告**——各幣尾巴厚度差 20 倍，池化會被少數幣主導

## 6. 停止條件（凍結）

- β1 被 `vwap_dist` 吸收（|t| < 1.5）→ H1 REJECT，H2/H3 不做
- 兩側都 REJECT → 整條線結案
- 一側 PASS 一側 REJECT → 只保留 PASS 側，**不池化**
- 任一側 INCONCLUSIVE → 該側**不下判決**，記錄需要多少樣本才判得動

## 7. 檢定總數與多重比較

主檢定 **2**（兩側 × L2 × τ=1h）。BH 對這 2 個修正。
穩健性 (2 側 × 3 lookback × 5 τ 的 β1 = 30) + (分位差 3 版 × 2 側 = 6)
+ (逐幣 18) + (五分位 2) + (冷卻期 3) = **59**，全部標明為穩健性、
**不進 PASS/REJECT**，但在報告中一併呈現以免挑格。
